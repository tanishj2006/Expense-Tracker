# 💰 Expense Tracker

A simple and user-friendly Expense Tracker built with **Python and PyQt**.  
This project helps you record daily expenses, store them in a CSV file, and view summaries with an intuitive GUI.  
It’s designed to make personal finance management easier and more visual.

---

## 🚀 Features
- ➕ Add new expenses with amount, category, and date  
- 📂 Categorize expenses (e.g., Food, Travel, Shopping, etc.)  
- 📊 View daily, weekly, or monthly spending summaries  
- 📈 Generate simple reports and analyze spending patterns  
- 🖥️ Clean and interactive **PyQt-based GUI**  

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Database:** CSV file  
- **Libraries Used:**  
  - `pandas` – for data handling  
  - `numpy` – for calculations  
  - `PyQt5` (`QWidget`, etc.) – for GUI
